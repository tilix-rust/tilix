### 1. Pure Domain Model: `DockPosition` & `calculate_dock_position` (`TASK-0008-1`)
- **Target Files:** `src/model/layout.rs`, `src/model/mod.rs`
- **Step 1 (TDD Test-First):** In `src/model/layout.rs`, write failing unit tests:
  - `test_dock_position_variants`: Asserts equality and debug representation of `DockPosition` enum variants (`Top`, `Bottom`, `Left`, `Right`, `Center`).
  - `test_calculate_dock_position_center_zone`: Asserts coordinates $(0.5, 0.5)$, $(0.3, 0.3)$, $(0.7, 0.7)$ evaluate to `DockPosition::Center` for a $100 \times 100$ bounding box.
  - `test_calculate_dock_position_directional_zones`: Asserts:
    - $(50.0, 5.0)$ evaluates to `DockPosition::Top`.
    - $(50.0, 95.0)$ evaluates to `DockPosition::Bottom`.
    - $(5.0, 50.0)$ evaluates to `DockPosition::Left`.
    - $(95.0, 50.0)$ evaluates to `DockPosition::Right`.
  - `test_calculate_dock_position_boundary_clamping`: Tests negative coordinates, values exceeding width/height, and zero/negative dimensions (defaulting safely to `Center`).
- **Step 2 (Implementation):**
  - Define `#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)] pub enum DockPosition { Top, Bottom, Left, Right, Center }`.
  - Implement `pub fn calculate_dock_position(x: f64, y: f64, width: f64, height: f64) -> DockPosition`.
  - In `src/model/mod.rs`, re-export `DockPosition` and `calculate_dock_position`.
- **Validation:** `cargo test --lib model::layout` passes 100%.

### 4. DND Controller & Active Drag Registry (`TASK-0008-4`)
- **Target File:** `src/ui/dnd.rs`
- **Step 1 (Implementation):**
  - Implement `ActivePaneDrag` struct and thread-local `ACTIVE_PANE_DRAG`.
  - Enhance `setup_pane_drag_source`:
    - On `connect_prepare`: record active drag in `ACTIVE_PANE_DRAG`.
    - On `connect_drag_cancel`: check if reason is `gdk::DragCancelReason::NoTarget`. If source session/window pane count $> 1$, invoke detach handler.
    - On `connect_drag_end`: clear `ACTIVE_PANE_DRAG`.
  - Enhance `setup_pane_drop_target`:
    - On `connect_motion`: check if hovering self (if so, hide indicator). Otherwise compute `calculate_dock_position`, call `pane.show_drop_indicator(pos)`, and return `gdk::DragAction::MOVE`.
    - On `connect_leave`: call `pane.hide_drop_indicator()`.
    - On `connect_drop`: call `pane.hide_drop_indicator()`, compute dock position, and dispatch `on_dock(src_id, dest_id, position)`.
- **Validation:** `cargo check --all-targets` passes with 0 warnings.
