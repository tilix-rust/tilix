  - Horizontal and vertical splitting.

- Implement `src/pty/shell.rs`:

  - Wire `window-title-changed` signal to update header label.

- **Validation:** `cargo check --lib` succeeds.

### 4. Reactive Paned Projection & SessionView (`TASK-0001-4`)
- Implement `src/ui/session_view.rs`:
  - Manage `LayoutTree` and `HashMap<PaneId, TerminalPane>`.
  - Implement recursive projection from `LayoutNode` into nested `gtk::Paned`.
  - Reparent existing `TerminalPane` widgets into newly composed `gtk::Paned` nodes without destroying terminal instances.
  - Implement `split_active(orientation)`: allocates next `PaneId`, updates model, adds new `TerminalPane`, and rebuilds paned projection.
  - Implement `close_active()`: removes pane, updates model, collapses paned containers, and focuses adjacent pane.
  - Implement `focus_adjacent(direction)`: queries model and calls `grab_focus()`.
- **Validation:** `cargo check --lib` succeeds.
