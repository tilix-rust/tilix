### 3. [x] Terminal Font Zoom API & Capture Scroll Controller (`TASK-0013-3`)
- **Target Files:** `src/ui/terminal_pane.rs`
- **Step 1:** In `src/ui/terminal_pane.rs`:
  - Define constants:
    - `pub const ZOOM_STEP: f64 = 0.1;`
    - `pub const ZOOM_MIN: f64 = 0.2;`
    - `pub const ZOOM_MAX: f64 = 5.0;`
    - `pub const ZOOM_NORMAL: f64 = 1.0;`
  - Implement methods on `TerminalPane`:
    - `pub fn font_scale(&self) -> f64`
    - `pub fn zoom_in(&self)`
    - `pub fn zoom_out(&self)`
    - `pub fn zoom_normal(&self)`
- **Step 2:** In `TerminalPane::new`:
  - Create `gtk::EventControllerScroll` with `EventControllerScrollFlags::VERTICAL`.
  - Set propagation phase to `gtk::PropagationPhase::Capture`.
  - In `connect_scroll`:
    - Check `controller.current_event_state()`:
      - If `CONTROL_MASK` is present and neither `SHIFT_MASK` nor `ALT_MASK` is present:
        - If `dy < 0.0`: zoom in, return `glib::Propagation::Stop`.
        - If `dy > 0.0`: zoom out, return `glib::Propagation::Stop`.
        - Else: return `glib::Propagation::Proceed`.
      - Else: return `glib::Propagation::Proceed`.
  - Add controller to `terminal`: `terminal.add_controller(scroll_controller);`.
- **Validation:** `cargo test --test test_phase13_zoom_and_alt_drag test_phase13_terminal_pane_zoom` passes.

### 5. [x] Alt + Left-Click Terminal Drag Source & DnD Gating (`TASK-0013-5`)
- **Target Files:** `src/ui/dnd.rs`, `src/ui/terminal_pane.rs`
- **Step 1:** In `src/ui/dnd.rs`:
  - Update `setup_pane_drag_source(widget: &impl IsA<gtk::Widget>, pane: TerminalPane, require_alt: bool)`.
  - When `require_alt` is true:
    - In `connect_begin`: check `gesture.current_event_state().contains(gtk::gdk::ModifierType::ALT_MASK)`. If false, set sequence state to `gtk::EventSequenceState::Denied`.
    - In `connect_prepare`: check `source.current_event_state().contains(gtk::gdk::ModifierType::ALT_MASK)`. If false, return `None`.
  - When `require_alt` is false:
    - Normal drag initiation without Alt gating.
- **Step 2:** In `src/ui/terminal_pane.rs`:
  - In `setup_drag_source(&self)`:
    - Attach drag source to header: `setup_pane_drag_source(&self.header, self.clone(), false);`.
    - Attach drag source to terminal: `setup_pane_drag_source(&self.terminal, self.clone(), true);`.
