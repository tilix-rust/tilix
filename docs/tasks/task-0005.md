### 3. Reactive Projection: Window Style in `TilixWindow` (`TASK-0005-3`)
- **Step 1 (TDD Test-First):** In `src/ui/window.rs` tests:
  - Add unit test `test_window_style_header_bar_toggle` (guarded by `if gtk::init().is_err() { return; }`): Creates an empty window, verifies `apply_window_style_to_all_windows(WindowStyle::HideToolbar)` hides the header bar, and `apply_window_style_to_all_windows(WindowStyle::Normal)` reveals it.
- **Step 2 (Implementation):**
  - Define thread-local `WINDOW_HEADER_BARS: RefCell<Vec<glib::WeakRef<adw::HeaderBar>>>` in `src/ui/window.rs`.
  - In `TilixWindow::new_empty`:
    - Read configuration: `let cfg = crate::model::AppConfig::load();`
    - Apply initial visibility: `header_bar.set_visible(cfg.window_style != crate::model::WindowStyle::HideToolbar);`
    - Register weak ref: `WINDOW_HEADER_BARS.with(|bars| bars.borrow_mut().push(header_bar.downgrade()));`
  - Implement public function `pub fn apply_window_style_to_all_windows(style: WindowStyle)` retaining valid weak refs and updating visibility.
  - Implement public function `pub fn apply_wide_handle_to_all_sessions(wide: bool)` broadcasting to all sessions in `WIDGET_TO_SESSION`.
- **Validation:** `cargo test --lib ui::window` passes.
