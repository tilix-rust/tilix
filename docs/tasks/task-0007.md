## Sequenced Subtasks

### 1. Headless Domain Model & Action Catalog (`TASK-0007-1`)
- **Target File:** `src/model/keybindings.rs`
- **Step 1 (TDD Test-First):** In `src/model/keybindings.rs`, write failing unit tests:
  - `test_default_keybindings_empty`: Asserts `KeybindingsConfig::default().custom.is_empty()`.
  - `test_action_catalog_completeness`: Asserts `ACTION_CATALOG.len() == 24` and covers all expected action IDs (`win.new-tab`, `win.close-pane`, `win.close-tab`, `win.split-right`, `win.split-down`, etc.).
  - `test_effective_accel_default_resolution`: For non-customized actions, `get_effective_accel` returns the primary default accelerator.
  - `test_effective_accel_custom_override`: When a custom override is inserted into `custom`, `get_effective_accel` returns the custom string.
  - `test_effective_accel_disabled`: Setting custom override to `""` returns empty string (disabled).
  - `test_is_customized`: Checks that `is_customized` returns `false` by default, `true` after override, and `false` after resetting.
  - `test_reset_action_and_reset_all`: Tests `reset_action` on a single action and `reset_all` clearing all overrides.
- **Step 2 (Implementation):**
  - Define `ActionCategory` enum (`SessionAndTabs`, `SplitsAndLayout`, `Navigation`, `ViewAndSettings`) with `title(&self) -> &'static str`.
  - Define `ActionShortcutDef` struct (`id`, `title`, `description`, `category`, `default_accels: &'static [&'static str]`).
  - Declare `ACTION_CATALOG: &[ActionShortcutDef]` with all 24 actions.
  - Implement `KeybindingsConfig` struct (`pub custom: HashMap<String, String>`).
  - Implement `get_effective_accel`, `get_all_effective_accels`, `is_customized`, `set_custom_accel`, `reset_action`, and `reset_all`.
- **Validation:** `cargo test --lib model::keybindings` passes 100%.

### 2. Accelerator Normalization & Conflict Detection (`TASK-0007-2`)
- **Target File:** `src/model/keybindings.rs`
- **Step 1 (TDD Test-First):** In `src/model/keybindings.rs`, add failing unit tests:
  - `test_normalize_accelerator_canonicalization`: Verifies `<Shift><Primary>t` normalizes to `<Primary><Shift>t`, `<Control><Shift>w` to `<Primary><Shift>w`, and `<ctrl><alt>up` to `<Primary><Alt>Up`.
  - `test_normalize_accelerator_empty`: Verifies empty or whitespace strings return `""`.
  - `test_check_conflict_detects_collision`: Setting candidate `<Primary><Shift>t` for `win.split-right` returns `Some(ConflictInfo)` referencing `win.new-tab`.
  - `test_check_conflict_self_ignored`: Candidate `<Primary><Shift>t` for `win.new-tab` does not conflict with itself.
  - `test_check_conflict_empty_candidate_no_conflict`: Setting candidate `""` never conflicts.
  - `test_check_conflict_with_alias_modifiers`: Setting `<Shift><Control>t` detects conflict with `<Primary><Shift>t`.
- **Step 2 (Implementation):**
  - Implement `normalize_accelerator(accel: &str) -> String` using pure Rust token parsing.
  - Define `ConflictInfo` struct (`action_id: String, action_title: String, conflicting_accel: String`).
  - Implement `check_conflict(&self, target_action_id: &str, candidate_accel: &str) -> Option<ConflictInfo>`.
- **Validation:** `cargo test --lib model::keybindings` passes 100%.
