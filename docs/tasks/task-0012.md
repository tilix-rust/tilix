## Sequenced Subtasks

### 1. [x] TDD Test-First Framework for Phase 12 Window Geometry (`TASK-0012-1`)
- **Target Files:** `tests/test_phase12_window_geometry.rs`
- **Step 1 (TDD Test-First):** Create integration test suite `tests/test_phase12_window_geometry.rs` with comprehensive tests wrapped in `run_gtk_test`:
  - `test_phase12_measure_cell_size_vte_monospace`: Verifies `measure_cell_size(&Profile::default())` returns positive `(w, h)` (e.g. `w >= 7 && h >= 14`).
  - `test_phase12_cell_scale_proportionality`: Verifies that `cell_width_scale = 1.5` and `cell_height_scale = 1.5` scale the measured cell dimensions.
  - `test_phase12_calculate_window_size_default_80x24`: Verifies standard profile 80x24 calculation produces expected window dimensions with all default chrome.
  - `test_phase12_calculate_window_size_simulated_hidpi_196dpi`: Simulates 196 DPI cell (16x35) with 80x24 grid, verifying window size ~1296x960 instead of hardcoded 900x600.
  - `test_phase12_calculate_window_size_custom_grid`: Tests custom columns/rows (e.g. 132 columns x 43 rows).
  - `test_phase12_chrome_toggles`: Verifies pixel subtractions when `show_scrollbar = false`, `window_style = WindowStyle::HideToolbar`, `show_tab_bar = false`, and `pane_title_style = PaneTitleStyle::None`.
  - `test_phase12_screen_clamping_max_bounds`: Verifies that a large terminal grid on an 800x600 monitor clamps to 90% (720x540).
  - `test_phase12_screen_clamping_min_bounds`: Verifies that a tiny terminal grid (10x5) clamps to minimum 300x200.
  - `test_phase12_fallback_on_zero_or_negative_dimensions`: Verifies fallback to default `(900, 600)` when font cell dimensions are invalid.
  - `test_phase12_tilix_window_instantiation_uses_calculated_size`: Verifies that `TilixWindow::new_empty` applies the calculated size to `window.default_size()`.
- **Validation:** `cargo test --test test_phase12_window_geometry` fails to compile or fails prior to implementation.

### 2. [x] Pure Window Geometry & Cell Measurement Module (`TASK-0012-2`)

- **Step 1:** Create `src/ui/geometry.rs` defining:

  - `calculate_window_size_with_bounds(profile: &Profile, app_config: &AppConfig, monitor_size: Option<(i32, i32)>) -> (i32, i32)`.
  - `calculate_window_size_for_profile(profile: &Profile, app_config: &AppConfig, monitor: Option<&gdk::Monitor>) -> (i32, i32)`.
