### 1. [x] Dependencies & Pure Domain OSC 52 Parser (`TASK-0014-1`)
- **Target Files:** `Cargo.toml`, `src/pty/osc52.rs`, `src/pty/mod.rs`
- **Step 1:** In `Cargo.toml`:
  - Add `libc = "0.2"` under `[dependencies]`.
- **Step 2:** In `src/pty/osc52.rs`:
  - Implement `Osc52Target` enum (`Clipboard`, `Primary`, `Secondary`, `CutBuffer(u8)`) with `from_char` and `to_char`.
  - Implement `Osc52Operation` enum: `Write(Vec<u8>)`, `Query`, `Clear`.
  - Implement `Osc52Event` struct: `pub targets: Vec<Osc52Target>`, `pub operation: Osc52Operation`.
  - Implement `Osc52StreamParser`:
    - States: `Ground`, `Escape`, `OscHeader`, `OscTargets`, `OscPayload`, `EscapeInPayload`.
    - Safety limit: `MAX_OSC52_PAYLOAD_SIZE = 5 * 1024 * 1024` (5 MB).
    - Method `pub fn process(&mut self, chunk: &[u8]) -> (Vec<u8>, Vec<Osc52Event>)`.
    - Terminator handling: BEL (`0x07`), 7-bit ST (`\x1b\\`), 8-bit ST (`0x9C`).
    - Base64 decode via `glib::base64_decode`.
    - Passthrough preservation for non-OSC bytes and non-52 OSC sequences (such as OSC 7).
  - Implement helper `pub fn encode_osc52_response(target: Osc52Target, data: &[u8]) -> String` using `glib::base64_encode`.
  - Add comprehensive pure-domain unit tests in `src/pty/osc52.rs` verifying targets, operations, streaming chunk splits, and buffer limits.
- **Step 3:** In `src/pty/mod.rs`:
  - Expose `pub mod osc52;` and re-export `Osc52Target`, `Osc52Operation`, `Osc52Event`, `Osc52StreamParser`, `encode_osc52_response`.
- **Validation:** `cargo test pty::osc52` passes with 0 failures.

### 3. [x] In-Process PTY Proxy Interceptor (`TASK-0014-3`)
- **Target Files:** `src/pty/proxy.rs`, `src/pty/mod.rs`
- **Step 1:** In `src/pty/proxy.rs`:
  - Implement `ProxyPtyPair` with `open() -> Result<Self, std::io::Error>` calling `libc::openpty`.
  - Implement `PtyProxy`:
    - Fields: `inner_master: RawFd`, `inner_slave: RawFd`, `outer_master: RawFd`, `outer_slave: RawFd`, `running: Arc<AtomicBool>`.
    - Method `new() -> Result<Self, std::io::Error>`.
    - Methods `inner_slave_fd(&self) -> RawFd`, `outer_master_fd(&self) -> RawFd`.
    - Method `start<F, Q>(&self, on_osc52_event: F, on_query: Q)` spawning:
      * Thread 1: Input forwarder (`outer_slave` -> `inner_master`).
      * Thread 2: Output interceptor (`inner_master` -> `Osc52StreamParser` -> `outer_slave` + callbacks).
    - Method `set_window_size(&self, rows: u16, cols: u16)` sending `TIOCSWINSZ` to `inner_master`.
    - Method `sync_size_from_outer(&self)` reading `TIOCGWINSZ` from `outer_slave` and applying to `inner_master`.
    - Method `shutdown(&self)`.
  - Add unit tests in `src/pty/proxy.rs` verifying PTY pair creation and bidirectional forwarding.
- **Step 2:** In `src/pty/mod.rs`:
  - Expose `pub mod proxy;` and re-export `ProxyPtyPair`, `PtyProxy`.
