  - Close popover via `popover.popdown()`.
  - Re-focus entry with `target_entry.grab_focus()`.

### 6. [x] Live Dynamic Title Synchronization in `SessionView` (`TASK-0011-6`)
- **Target Files:** `src/ui/session_view.rs`
- **Step 1:** In `SessionView`:
  - Implement dynamic session title calculation helper `compute_session_title(&self) -> String`:

### 7. [x] Live Dynamic Title Synchronization in `TilixWindow` (`TASK-0011-7`)
- **Target Files:** `src/ui/window.rs`
- **Step 1:** In `TilixWindow`:
  - Store a reference to `title_widget: adw::WindowTitle` in `TilixWindow`.
  - Implement `update_window_and_tab_titles(&self)`:
    - For each open tab page, update its title with the session's current `active_title()`.
    - Compute resolved window title:
      - Retrieves `AppConfig::load().app_title`.
      - Gathers window tokens (`appName`, `sessionName`, `sessionNumber`, `sessionCount`), active session tokens, and active terminal tokens.
      - Evaluates template via `expand_title_tokens_scoped(&pattern, TitleEditScope::Window, &ctx)`.
    - Set window title on `self.window.set_title(Some(&resolved_title))`.
    - Set header bar title on `self.title_widget.set_title(&resolved_title)`.
- **Step 2:** Connect title update triggers:
  - `tab_view.connect_selected_page_notify`: update window title on tab switch.
  - `tab_view.connect_page_attached` / `detached`: update window title when tabs are opened or closed.
  - `session.connect_title_changed`: update tab page title and window title.
- **Step 3:** Implement global broadcast helper `pub fn apply_title_settings_to_all_windows()`:
  - Iterates all registered windows and sessions, invoking title updates across all open windows.
- **Validation:** Window header bar and tab titles update live on tab switch, terminal activity, and preference change.
