- **Validation:** `cargo check --all-targets` passes with 0 warnings.

### 3. Phase 3 Polish: Dynamic Notification Title Lookup (`TASK-0004-3`)
- **Step 1 (Implementation):**
  - In `src/ui/session_view.rs` (`create_pane`), remove pre-captured `let title_bell = pane.title();` and `let title_exit = pane.title();`.
  - Downgrade `panes` into `panes_weak = Rc::downgrade(panes);` and clone for bell and child-exit closures.
  - At event firing time, dynamically lookup the title via:
    `panes.borrow().get(&p_id).map(|p| p.title()).unwrap_or_else(|| "Terminal".to_string())`.
